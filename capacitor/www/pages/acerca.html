📐 Arquitectura del Sistema
  • Frontend: PWA SPA en HTML5, CSS vanilla (tema oscuro azul institucional) y JavaScript ES6 modular con Service Worker.
  • Backend: PHP con arquitectura MVC desacoplada, PDO con consultas preparadas, hashing Bcrypt y token de dispositivo.
  • Base de Datos: MariaDB / MySQL con 9 tablas relacionales, cola de comandos asíncrona y logs de auditoría.
  • Hardware ESP32: C++ / Arduino / PlatformIO, polling no bloqueante (1s), LED IR en GPIO4, receptor IR en GPIO15 y relés de 220V en GPIO26 y GPIO27.
  • Módulo Dron: Adaptadores para DJI Tello, drones HTTP genéricos, enlaces UDP directos y simulador de prueba.
